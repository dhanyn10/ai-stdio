# GitHub Sync & Repo Integratio

Synchronize your documentation directly with a GitHub repository for team collaboration and code-aligned documentation.

* * *

## 🔧 Configuration Steps

1.  Generate a **GitHub Personal Access Token** with `repo` scope.
2.  Enter your repository details in **Sync Settings**:
    *   **Repository Owner**: `your-username`
    *   **Repository Name**: `my-docs-repo`
    *   **Branch**: `main`
    *   **Folder Path**: `docs/`
3.  Click **Test Connection** & **Sync Now**.

* * *

## ⏱️ Inline Timing Tracking

Every commit made in GitSync Notes is mapped to Git timing standards:

*   **Commit Message**: User message or auto-generated message.
*   **Timestamp**: Preserved accurate timestamp for audit trails.
