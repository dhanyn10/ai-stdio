# Markdown Syntax Cheat Sheet 📝

Quick reference for writing notes in GitSync Notes:

## Headings
# Heading 1
## Heading 2
### Heading 3

## Typography
*Italic text* or _italic text_
**Bold text** or __bold text__
~~Strikethrough~~
